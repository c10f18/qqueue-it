# 화면 문구 목록 (긴 것 위주)

지금 화면에 쓰이고 있는 문구입니다. 바꾸고 싶은 줄이 있으면 **문구** 칸을 직접 고쳐 주세요.
`{…}` 부분은 숫자나 이름이 들어가는 자리입니다.

용어는 아래로 통일합니다.

| 쓰는 말 | 쓰지 않는 말 |
|---|---|
| 카테고리 | 레인 |
| 작업 | 노드 |
| 뷰 | 시점 |

## A. 화면에 항상 보이는 글

| 번호 | 어디 | 문구 |
|---|---|---|
| A1 | 보드 목록 (보드가 없을 때) | 뀨잇 |
| A2 | 보드 목록 (검색 결과 없음) | "{검색어}"에 맞는 보드가 없습니다. |
| A3 | 보드 목록 (검색 중 개수) | 검색 결과 {n}개 / 전체 {m}개 |
| A4 | 템플릿 카드 | 카테고리 {n}개 · 슬롯 {n}개 · 작업 {n}개 |
| A5 | 보기 모드 리스트 (작업이 없을 때) | 작업 없음 |
| A6 | 보기 모드 리스트 | ⋯ 숨겨진 슬롯 {n}개 |
| A7 | 수정 모드 (카테고리를 다 숨겼을 때) | 표시 중인 카테고리가 없습니다 |
| A8 | 그래프 (작업이 없을 때) | 표시할 작업이 없습니다 |
| A9 | 설정 › 그래프 | 그래프 위에 보드 이름 표시 |
| A10 | 설정 › 그래프 | 진행도를 백분율(%)로 표시 |
| A11 | 설정 › 작업 › 완료 표시 | 192×192px 사이즈, 정사각형 이미지 권장 |
| A12 | 설정 › 라벨 | + 라벨 그룹 추가 ({n}/8) |
| A13 | 글꼴 팝업 | Google Fonts의 무료 글꼴입니다. |
| A14 | 작업 편집창 | 단색 (그래프 작업과 카드의 원 색) |
| A15 | 작업 편집창 | 사진 (첨부하면 아이콘 대신 표시) |
| A16 | 작업 편집창 | 태그 (쉼표로 구분, 최대 5개) |
| A17 | 작업 편집창 | 데드라인 (정렬용) |
| A18 | 작업 편집창 | 뷰에 표시 |
| A19 | 작업 우클릭 메뉴 › 링크 필터 | 체크한 카테고리의 다음 작업에 연결 |
| A20 | 수정 모드 툴바 | 자동 저장 |

## C. 창(대화상자) 안의 글

| 번호 | 어디 | 문구 |
|---|---|---|
| C1 | 복구 창 | 백업 파일(.json)의 보드와 템플릿 데이터를 복구합니다. |
| C2 | 복구 창 (파일 선택 전) | 선택한 파일 없음 |
| C3 | 복구 창 (검사 통과) | 복구할 수 있는 파일입니다: 보드 {n}개, 템플릿 {m}개 |
| C4 | 복구 창 (검사 실패) | 복구할 수 없는 파일입니다: {이유} |
| C5 | 복구 창 | 기존 데이터 전체 삭제 후 복구 |
| C6 | 복구 창 (체크 안 함) | 지금 있는 보드는 그대로 두고, 백업 보드를 목록에 추가합니다. |
| C7 | 복구 창 (체크함) | 지금 있는 보드 {n}개와 템플릿 {m}개를 모두 지운 뒤 복구합니다. 되돌릴 수 없습니다. |
| C8 | 보드 삭제 확인 | "{이름}" 보드를 삭제할까요? |
| C9 | 보드 삭제 확인 | 선택한 보드 {n}개를 삭제할까요? |
| C10 | 보드 삭제 확인 | 보드 {n}개를 전부 삭제할까요? |
| C11 | 보드 삭제 확인 | 삭제한 보드는 되돌릴 수 없습니다. |
| C12 | 카테고리 삭제 창 | 이 카테고리에 작업이 {n}개 있습니다. 어떻게 할까요? |
| C13 | 카테고리 삭제 창 | 되돌리기(Ctrl+Z)로 복구할 수 있습니다. |
| C14 | 일괄 진행 창 | 일괄 완료 처리 |
| C15 | 일괄 진행 창 (슬롯 목록) | {n}번 슬롯 — {작업 이름들} / (비어 있음) |

## D. 잠깐 떴다 사라지는 알림

| 번호 | 언제 | 문구 |
|---|---|---|
| D1 | 백업 후 | 보드 {n}개와 템플릿 {m}개를 백업 파일로 내보냈습니다. |
| D2 | 복구 후 (더하기) | 보드 {n}개와 템플릿 {m}개를 복구해 목록에 더했습니다. |
| D3 | 복구 후 (전체 삭제) | 기존 데이터를 모두 지우고 보드 {n}개와 템플릿 {m}개를 복구했습니다. |
| D4 | 보드 삭제 후 | 보드 {n}개를 삭제했습니다. |
| D5 | 보드 복제 후 | 보드를 복제했습니다. |
| D6 | 템플릿 저장 후 | 템플릿으로 저장했습니다. |
| D7 | 저장 실패 | 저장에 실패했습니다. |

## E. 마우스를 올리면 나오는 설명(툴팁)

| 번호 | 어디 | 문구 |
|---|---|---|
| E1 | 수정 모드 › 자동 저장 | 자동으로 저장됩니다. |
| E2 | 수정 모드 › 설정 버튼 | 테마·그래프·작업·라벨·라인·레이아웃 설정 |
| E3 | 수정 모드 › 완료 버튼 | 보기 모드로 전환 |
| E4 | 보기 모드 ☰ › 일괄 진행 | 지정한 슬롯까지 일괄 완료 처리 |
| E5 | 그래프 도구 › 회전 | 회전 (끌기. Shift 또는 우클릭 끌기도 가능) |
| E6 | 그래프 도구 › 배율 | 지금 확대 배율. 누르면 100%로 봅니다 |
| E7 | 그래프 도구 › 뷰 리셋 (저장된 뷰 있음) | 뷰 리셋: 저장된 뷰로 돌아가기 (더블클릭) |
| E8 | 그래프 도구 › 뷰 리셋 (저장된 뷰 없음) | 뷰 리셋: 화면에 맞추기 (더블클릭). 저장된 뷰가 없습니다 |
| E9 | 그래프 도구 › 뷰 저장 | 뷰 저장: 지금의 확대·이동·회전을 보기 모드에서 보여 줄 뷰로 저장 |
| E10 | 그래프 도구 › 뷰 저장 (저장된 상태) | 현재 뷰가 저장된 뷰입니다 |
| E11 | 설정 › 백분율 토글 | 카드에 진행도 슬라이더와 % 숫자가, 그래프 작업에 진행률이 나옵니다. |
| E12 | 설정 › 완료 표시 › 이미지 칸 (이미지 없음) | 이미지 추가. 20MB 이하, 64×64px 이상 정사각형 이미지 |
| E13 | 설정 › 완료 표시 › 이미지 칸 (이미지 있음) | 내 이미지 |
| E14 | 설정 › 기본값으로 (모든 탭 공통) | 기본값으로 되돌립니다 |
| E15 | 라벨 그룹 › 순서 번호 | {n}번째 |
| E16 | 라벨 그룹 › "이름" 그룹 | 작업 이름 |
| E17 | 라벨 그룹 › 삭제 | 그룹 삭제 |
| E18 | 라벨 그룹 › 각도 노브 | 각도 조정 (방향키: 1°, Shift+방향키: 15°) |
| E19 | 카드의 라벨 입력 줄 | {그룹 이름} |
| E20 | 카드의 라벨 입력 줄 (숨긴 그룹) | {그룹 이름} (숨긴 그룹: 그래프에 표시되지 않음) |
| E21 | 카테고리 추가 버튼 (5개일 때) | 카테고리는 최대 5개 |
| E22 | 카테고리 메뉴 › 삭제 (1개 남았을 때) | 마지막 카테고리는 삭제할 수 없습니다 |
| E23 | 슬롯 손잡이 | 끌어서 슬롯 전체 이동 |
| E24 | 보드 목록 › 정렬 버튼 | {기준} {내림차순/오름차순} |
| E25 | 영역 경계선 | 끌어서 크기 조절 |

## F. 오류 문구 (잘못 입력했을 때 빨간 알림으로 뜸)

| F9 | 태그는 작업당 최대 5개입니다. |

| F15 | 가져올 수 없는 파일입니다: {이유} |
| F16 | (이유) JSON 형식이 아닙니다. |
